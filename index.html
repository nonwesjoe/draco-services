② 批量文件处理器 · Python CLI

客户：行政 / 设计 / 资料归档 / 电商 —— 几百个文件重复改名、转换、加水印，人工做要一天
批量重命名前缀+日期+序号+关键词替换
PDF→图片指定 DPI
图片→PDF多图合并成一份
CSV→Excel含中文 BOM 兼容
图片压缩可设质量与最大宽
PDF 批量水印自定义文字
批量提取文本PDF/Word/Excel 合并成一个 txt
零人工介入一条命令跑完全部文件
# 批量改名（加前缀+日期+序号）
python batch_tool.py rename ./资料 -o ./整理后 --prefix 项目A --date "%Y%m%d"

# PDF 批量转图片
python batch_tool.py convert pdf2img ./合同 -o ./图片 --dpi 200

# 100 张图合并成一个 PDF
python batch_tool.py convert img2pdf ./照片 -o ./合集.pdf

# 批量提取文字，合并成一个文件
python batch_tool.py extract ./全部资料 -o ./汇总.txt
